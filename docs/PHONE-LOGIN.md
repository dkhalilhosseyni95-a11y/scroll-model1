# ورود با شماره موبایل (OTP)

ورود و ثبت‌نام حساب کاربری در قالب MOON با شماره موبایل کار می‌کند و کد تأیید از طریق یک «درگاه پیامک» ارسال می‌شود. منطق آن در افزونه `moon-core` و در فایل `includes/modules/class-moon-otp.php` است.

## آنچه بدون تنظیم اضافه کار می‌کند

- صفحه «حساب کاربری» سه حالت دارد: **ورود با کد پیامکی**، **ورود با رمز عبور** و **ثبت‌نام**.
- شماره‌ها به شکل `09xxxxxxxxx` نرمال می‌شوند (ارقام فارسی هم پذیرفته می‌شود).
- کاربر با شماره موبایل به‌عنوان نام کاربری ساخته می‌شود و در متای `billing_phone` ذخیره می‌شود؛ سفارش‌ها و آدرس‌ها به همان حساب وصل می‌شوند.
- کد ۶ رقمی، ۳ دقیقه اعتبار، حداکثر ۵ تلاش و ۶۰ ثانیه فاصله بین دو درخواست.
- اگر افزونه **Digits** فعال باشد، فرم و درگاه‌های پیامک Digits جای فرم قالب را می‌گیرند و نیازی به تنظیم دیگری نیست.

## اتصال به درگاه پیامک

برای ارسال واقعی پیامک، این فیلتر را در یک افزونه کوچک (یا `functions.php` قالب فرزند) اضافه کنید:

```php
add_filter( 'moon_core_send_sms', function ( $sent, $phone, $text ) {
    // نمونه: پنل پیامکی دلخواه شما
    $response = wp_remote_post( 'https://api.example-sms.ir/send', array(
        'body' => array(
            'username' => 'USER',
            'password' => 'PASS',
            'to'       => $phone,
            'text'     => $text,
        ),
    ) );

    return ! is_wp_error( $response ) && 200 === (int) wp_remote_retrieve_response_code( $response );
}, 10, 3 );
```

همچنین می‌توانید پیش از ارسال، کد را در اختیار درگاه خودتان بگذارید:

```php
add_action( 'moon_core_otp_code', function ( $phone, $code, $message ) {
    // ارسال با کلاس یا تابع افزونه پیامکی نصب‌شده
}, 10, 3 );
```

نام کاربری که ساخته می‌شود از این فیلتر قابل تغییر است:

```php
add_filter( 'moon_core_phone_auth_mode', fn() => 'digits' ); // اجبار به استفاده از Digits
```

## حالت آزمایشی

در محیط `local` (همان سندباکس) اگر هیچ درگاهی متصل نباشد، کد در پاسخ درخواست برگشت داده می‌شود تا جریان ورود قابل تست باشد و در `wp-content/debug.log` هم ثبت می‌شود. در محیط `production` هیچ‌وقت کد به مرورگر فرستاده نمی‌شود؛ برای ارسال واقعی باید یکی از دو راه بالا پیاده شود.

## بررسی سریع

1. به `/my-account/` بروید (وقتی وارد نشده‌اید).
2. شماره‌ای وارد کنید و «ارسال کد» را بزنید.
3. کد پیامک‌شده (یا کد حالت آزمایشی) را وارد کنید؛ باید وارد حساب شوید.
