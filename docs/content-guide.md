# راهنمای مدیریت محتوا

همه محتوای سایت از پیشخوان وردپرس مدیریت می‌شود؛ هیچ نوشتن کد لازم نیست.

## منوی DaniSite

پس از فعال‌سازی افزونه، یک منوی اختصاصی با آیکون هنر در پیشخوان اضافه می‌شود:

| زیرمنو | کاربرد |
| --- | --- |
| تنظیمات | اطلاعات تماس، شبکه‌های اجتماعی، دکمه اقدام، هیرو، سئو |
| راه‌اندازی و درون‌ریزی | ساخت/به‌روزرسانی تمام محتوای نمونه با یک کلیک + بازگردانی |
| پیام‌های تماس | پیام‌های ثبت‌شده از فرم تماس |
| خدمات، نمونه‌کارها، اعضای تیم، نظرات، پرسش‌های متداول | نوع‌های محتوای اختصاصی |

## نوع‌های محتوا

| نوع | کد | فیلدهای اختصاصی (در باکس «جزئیات») |
| --- | --- | --- |
| خدمات | `dani_service` | آیکون، خلاصه، لیست ویژگی‌ها، شماره ترتیب |
| نمونه‌کارها | `dani_project` + دسته‌بندی `dani_project_cat` | مشتری، سال، آدرس پروژه، دسته‌بندی |
| اعضای تیم | `dani_team` | سمت، لینک‌های شبکه اجتماعی، تصویر شاخص |
| نظرات مشتری | `dani_quote` | نام، سمت/شرکت، امتیاز، تصویر |
| پرسش‌های متداول | `dani_faq` | پاسخ کوتاه و شماره ترتیب |

نکته: تصویر شاخص هر نمونه‌کار و عضو تیم همان چیزی است که در کارت‌ها نمایش داده می‌شود؛ اندازه پیشنهادی ۸۰۰×۵۰۰ برای نمونه‌کار و ۸۰۰×۱۰۰۰ برای عضو تیم.

## ویجت‌های المنتور (دسته DaniSite)

- **چیدمان:** هدر، ناوبری، فوتر
- **هیرو:** هیرو، هیرو ویدیویی
- **محتوا:** درباره ما، تجربه، فرایند کاری، تیم، نظرات، آمار، پرسش‌ها، دکمه اقدام
- **خدمات:** لیست خدمات، کارت‌های خدمات، کارت خدمت
- **نمونه‌کارها:** گرید نمونه‌کارها (با فیلتر)، کاروسل نمونه‌کارها، کارت نمونه‌کار
- **وبلاگ:** آخرین مطالب، گالری، مقایسه قبل/بعد
- **عناصر:** فرم تماس، شبکه‌های اجتماعی، لوگو، دکمه، تصویر، ویدیو، عنوان، هدر صفحه، انیمیشن اسکرول

همه ویجت‌ها با پنل استایل المنتور کار می‌کنند (رنگ، تایپوگرافی، فاصله) و رنگ پیش‌فرض آن‌ها از پالت اصلی سایت گرفته می‌شود.

## شورت‌کدها

اگر با ویرایشگر کلاسیک کار می‌کنید (یا المنتور غیرفعال است) از این شورت‌کدها استفاده کنید:

```
[dani_home]                صفحه اصلی کامل
[dani_hero]                هیرو
[dani_services]            لیست خدمات
[dani_service_cards]       کارت‌های خدمات
[dani_experience]          بلوک تجربه
[dani_portfolio]           نمونه‌کارها (با فیلتر دسته)
[dani_portfolio_carousel]  کاروسل نمونه‌کارها
[dani_about]               درباره ما
[dani_workflow]            فرایند کاری
[dani_team]                تیم
[dani_testimonials]        نظرات
[dani_stats]               آمار
[dani_faq]                 پرسش‌های متداول
[dani_cta]                 دکمه اقدام
[dani_blog]                آخرین مطالب
[dani_contact]             فرم تماس
[dani_gallery]             گالری تصاویر
[dani_before_after]        مقایسه قبل/بعد
[dani_scroll]              انیمیشن اسکرول
```

پارامترهای مشترک: `limit` (تعداد)، `columns` (ستون)، `title` (عنوان بخش)، `surface` (پس‌زمینه جایگزین).

## تنظیمات سایت

**DaniSite → تنظیمات**

- **عمومی:** نام سایت، شعار، توضیح کوتاه برند (فوتر).
- **اطلاعات تماس:** ایمیل (گیرنده فرم تماس)، شماره نمایشی، شماره لینک `tel:`، نشانی، ساعات پاسخ‌گویی.
- **شبکه‌های اجتماعی:** لینک‌ها؛ هر فیلدی که خالی باشد نمایش داده نمی‌شود.
- **دکمه اقدام:** متن/لینک دکمه سراسری، متن پایین فوتر، کپی‌رایت.
- **هیرو:** متن بالای عنوان و آدرس ویدیو (MP4) و پوستر؛ ویدیو در موبایل به‌صورت خودکار می‌تواند نسخه سبک‌تر داشته باشد.
- **سئو:** توضیح متای پیش‌فرض، تصویر Open Graph، کد تأیید سرچ کنسول، عدم ایندکس صفحات جست‌وجو.

## سئو

افزونه به‌صورت داخلی این‌ها را تولید می‌کند:

- عنوان و توضیح متا برای همه صفحات (با اولویت توضیح هر صفحه، بعد توضیح پیش‌فرض)
- تگ canonical، تگ‌های Open Graph و Twitter Card
- داده ساختاریافته JSON-LD (سازمان/Schema)
- `robots` مناسب برای صفحات جست‌وجو و پیوندهای داخلی

اگر Yoast، Rank Math یا AIOSEO نصب و فعال باشد، این خروجی خودکار خاموش می‌شود تا متاتگ تکراری تولید نشود.

## منوها

سه جایگاه منو: **منوی اصلی**، **منوی فوتر**، **منوی قوانین و حریم خصوصی**. منوهای پیش‌فرض در درون‌ریزی ساخته و متصل می‌شوند؛ برای تغییر، نمایش → فهرست‌ها.

## بازگردانی درون‌ریزی

در صفحه «راه‌اندازی و درون‌ریزی»، دکمه بازگردانی آخرین نسخه پشتیبان گرفته‌شده پیش از درون‌ریزی را برمی‌گرداند (صفحات، تنظیمات و آپشن‌های تغییرکرده). این دکمه برای وقتی است که درون‌ریزی را اشتباه اجرا کرده‌اید.
