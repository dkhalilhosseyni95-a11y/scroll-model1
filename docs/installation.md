# راهنمای نصب MOON

این راهنما برای نصب روی هاست واقعی (وردپرس) نوشته شده است. نسخه پیشنهادی: وردپرس ۶.۸ یا بالاتر، PHP 8.1+.

## ۱. پیش‌نیازها

- وردپرس نصب‌شده با دسترسی مدیر
- قالب **Hello Elementor** (رایگان)
- افزونه **Elementor** (نسخه رایگان کافی است؛ برای Header/Footer و Theme Builder نیاز به **Elementor Pro** دارید)
- افزونه **WooCommerce**
- ووکامرس باید صفحات فروشگاه، سبد خرید، تسویه‌حساب و حساب کاربری را ساخته باشد (ووکامرس هنگام فعال‌سازی خودش می‌سازد)

## ۲. نصب قالب

پیشخوان ← **نمایش** ← **پوسته‌ها** ← **افزودن پوسته** ← جست‌وجوی `Hello Elementor` ← نصب ← فعال‌سازی.

> قالب فعال باید Hello Elementor بماند. فایل‌های قالب دست‌کاری نمی‌شوند؛ تمام استایل‌ها از افزونه Moon Core می‌آید.

## ۳. نصب افزونه Moon Core

1. پیشخوان ← **افزونه‌ها** ← **افزودن** ← **بارگذاری افزونه**
2. فایل `dist/moon-core.zip` را انتخاب کنید
3. **نصب** و سپس **فعال‌سازی**

پس از فعال‌سازی، در منوی پیشخوان آیتم **MOON** ظاهر می‌شود.

## ۴. نصب المنتور و ووکامرس

پیشخوان ← افزونه‌ها ← نصب `Elementor` و `WooCommerce` ← فعال‌سازی هر دو.

ترتیب مهم نیست، اما افزونه Moon Core باید **بعد از** ووکامرس فعال باشد تا هوک‌های فروشگاه ثبت شوند. اگر برعکس شد، یک‌بار Moon Core را غیرفعال/فعال کنید.

## ۵. راه‌اندازی محتوا (درون‌ریزی یک‌کلیکی)

پیشخوان ← **MOON** ← **راه‌اندازی** ← دکمه **ساخت محتوای نمایشی**.

این ابزار می‌سازد (بدون تکرار در اجراهای بعدی):

- دسته‌بندی‌ها: زنانه (پالتو و کت، پیراهن و بلوز، شلوار و دامن، شال و اکسسوری)، مردانه (کت و جلیقه، پیراهن، شلوار)
- ویژگی‌های واقعی محصول: `سایز`، `رنگ`، `جنس پارچه` (به‌عنوان Attribute ووکامرس با ترم‌ها)
- ۱۲ محصول **متغیر** با Variations واقعی سایز/رنگ، قیمت، قیمت تخفیف و تصویر
- صفحات: صفحه اصلی (Elementor)، درباره ما، تماس با ما، سوالات متداول، قوانین و مقررات، پیگیری سفارش، علاقه‌مندی‌ها
- قالب‌های `elementor_library` برای Header/Footer (برای Elementor Pro)
- منوی اصلی و تنظیمات فروشگاه (تومان، ایران، تهران)

> پیش از درون‌ریزی، تصاویر نمایشی داخل `assets/images/` افزونه قرار دارد و در کتابخانه رسانه کپی می‌شود. هیچ لینک خارجی استفاده نمی‌شود.

## ۶. صفحه اصلی

اگر صفحه اصلی به‌صورت خودکار تنظیم نشد: **تنظیمات** ← **خواندن** ← «آخرین نوشته‌ها» را به «یک صفحه ثابت» تغییر دهید و صفحه **صفحه اصلی** را انتخاب کنید.

صفحه اصلی از Container و ویجت‌های واقعی MOON ساخته شده و با کلیک روی **ویرایش با المنتور** کامل قابل ویرایش است.

## ۷. منو

هدر شیشه‌ای به‌طور پیش‌فرض منوی **دسته‌بندی‌های محصول** را نشان می‌دهد (زنانه/مردانه + زیرشاخه‌ها). برای استفاده از یک منوی وردپرس: پیشخوان ← **MOON** ← **هدر** ← فیلد «شناسه منوی وردپرس» را پر کنید (مثلاً `moon`).

## ۸. ویدئو و تصویر هیرو

1. فایل `assets/videos/hero.mp4` (همراه افزونه) یا ویدئوی خودتان را در **کتابخانه رسانه** آپلود کنید.
2. در صفحه اصلی، ویجت **هیرو سینمایی MOON** ← بخش **رسانه**: ویدئو MP4 و تصویر Poster را انتخاب کنید.

اگر ویدئو خالی باشد، فقط تصویر Poster نمایش داده می‌شود (بدون خطا). برای صرفه‌جویی در داده، گزینه «غیرفعال کردن ویدئو در موبایل» پیش‌فرض روشن است.

## ۹. Elementor Pro (اختیاری)

- قالب Header در `templates/elementor/header.json`
- قالب Footer در `templates/elementor/footer.json`
- قالب صفحه اصلی در `templates/elementor/home.json`

مسیر درون‌ریزی: پیشخوان ← **Templates** ← **Saved Templates** ← **Import Templates** ← انتخاب فایل JSON.
سپس در **Theme Builder** برای Header/Footer شرط نمایش (Entire Site) تعیین کنید و در **MOON ← هدر ← منبع هدر** گزینه «هدر قالب / المنتور پرو» را انتخاب کنید تا هدر افزونه دوباره رندر نشود.

بدون Elementor Pro هم سایت کامل کار می‌کند: هدر و فوتر شیشه‌ای از خود افزونه رندر می‌شوند و ظاهر یکسانی دارند.

## ۱۰. عیب‌یابی

| نشانه | علت و راه‌حل |
| --- | --- |
| فیلترهای فروشگاه نمایش داده نمی‌شوند | ووکامرس فعال نیست یا Moon Core قبل از ووکامرس بارگذاری شده؛ یک‌بار افزونه را غیرفعال/فعال کنید |
| صفحه فروشگاه «به‌زودی» نشان می‌دهد | ووکامرس ← تنظیمات ← سایت در حال راه‌اندازی ← گزینه «فروشگاه آماده است» را انتخاب کنید (یا `woocommerce_coming_soon = no`) |
| تصاویر محصولات مربع/بریده‌اند | ووکامرس ← تنظیمات ← محصولات ← تصاویر: نسبت ۳:۴ و عرض ۶۰۰، سپس «بازسازی تصاویر بندانگشتی» |
| قیمت‌ها با واحد اشتباه | ووکامرس ← تنظیمات ← عمومی ← واحد پول: تومان (IRT)، تعداد اعشار: ۰ |
| هدر قالب هم دیده می‌شود | در MOON ← هدر گزینه منبع هدر روی «هدر شیشه‌ای MOON» باشد |
| خطای ۵۰۳ در درون‌ریزی | حافظه PHP را به ۲۵۶M یا بیشتر افزایش دهید |
