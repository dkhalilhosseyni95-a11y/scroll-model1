# راهنمای نصب و راه‌اندازی روی هاست واقعی

این راهنما برای نصب پروژه روی یک هاست وردپرس معمولی (cPanel، DirectAdmin، سرور اختصاصی) نوشته شده است.

## ۱. پیش‌نیازها

| مورد | حداقل | پیشنهاد |
| --- | --- | --- |
| وردپرس | ۶.۸ (المنتور به آن نیاز دارد) | آخرین نسخه پایدار |
| PHP | ۸.۱ | ۸.۲ یا بالاتر |
| افزونه Elementor | نسخه رایگان، فعال | آخرین نسخه |
| حافظه PHP (`WP_MEMORY_LIMIT`) | ۲۵۶M | ۲۵۶M یا بیشتر |
| افزونه‌های دیگر | — | نیازی به قالب یا افزونه دیگری نیست |

نکته‌ها:

- قالب به هیچ افزونه صفحه‌سازی دیگری وابسته نیست؛ اگر Elementor غیرفعال باشد، صفحه‌ها با شورت‌کدهای خود افزونه نمایش داده می‌شوند و ظاهر حفظ می‌شود (فقط ویرایش بصری از دست می‌رود).
- اگر از افزونه سئو (Yoast، Rank Math یا AIOSEO) استفاده می‌کنید، متاتگ‌های همان افزونه اولویت می‌گیرند و خروجی سئوی داخلی خودکار کنار می‌رود؛ تنظیمات سئوی داخلی (منوی DaniSite → سئو) برای وقتی است که افزونه سئوی جداگانه نصب نکرده‌اید.

## ۲. نصب فایل‌ها

از پوشه `dist/` سه فایل را بردارید.

1. **قالب والد** — پیشخوان → نمایش → پوسته‌ها → افزودن پوسته → بارگذاری پوسته → `danisite-parent.zip` → نصب (فعلاً فعال نکنید).
2. **قالب فرزند** — همین مسیر با `danisite-child.zip` → نصب → **فعال‌سازی**.
3. **افزونه** — پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه → `danisite-core.zip` → نصب → **فعال‌سازی**.
4. **Elementor** — نصب و فعال‌سازی نسخه رایگان از مخزن وردپرس.

همیشه قالب فرزند را فعال کنید، نه والد را. تمام شخصی‌سازی‌های بعدی (CSS، بازنویسی قالب‌ها) در فرزند انجام می‌شود تا به‌روزرسانی قالب اصلی چیزی را از بین نبرد.

## ۳. درون‌ریزی یک‌کلیکی محتوا

منوی **DaniSite → راه‌اندازی و درون‌ریزی** را باز کنید و دکمه درون‌ریزی را بزنید. این کار به‌صورت idempotent انجام می‌شود:

- ۱۰ صفحه ساخته می‌شود (خانه، درباره ما، خدمات، نمونه‌کارها، وبلاگ، تماس، پرسش‌های متداول، قوانین و …) و در صورت وجود، همان صفحه به‌روزرسانی می‌شود (تکرار نمی‌شود).
- ۵ خدمت، ۵ نمونه‌کار، ۳ عضو تیم، ۳ نظر مشتری، ۶ پرسش متداول، ۴ مقاله نمونه.
- ۳ دسته‌بندی نمونه‌کار، هفت تصویر نمونه در کتابخانه رسانه.
- سه منو (اصلی، فوتر، قوانین) و اتصال آن‌ها به جایگاه‌ها.
- صفحه اصلی و صفحه وبلاگ، ساختار پیوند یکتا (`/%postname%/`)، منطقه زمانی تهران.
- تنظیمات پایه Elementor و پارامترهای قالب.
- نوشته «Hello world!» و صفحه «Sample Page» پیش‌فرض وردپرس (اگر دست‌نخورده و منتشرشده باشند) به سطل زباله منتقل می‌شوند تا سایت با محتوای پیش‌فرض تحویل نشود؛ از سطل زباله قابل بازگردانی است.

پیش از هر تغییر، یک نسخه پشتیبان از وضعیت فعلی گرفته می‌شود و دکمه **بازگردانی** همان صفحه، سایت را به وضعیت قبل از درون‌ریزی برمی‌گرداند.

اگر روی سایت محتوای واقعی دارید، لطفاً اول از دیتابیس بکاپ بگیرید و بعد درون‌ریزی را اجرا کنید؛ درون‌ریز فقط محتوایی را تغییر می‌دهد که با علامت داخلی خودش ساخته شده است، اما بکاپ همیشه توصیه می‌شود.

## ۴. تنظیمات واجب بعد از نصب

منوی **DaniSite → تنظیمات**:

| تب | چه چیزی را پر کنید |
| --- | --- |
| عمومی | نام سایت، شعار، توضیح کوتاه برند برای فوتر |
| اطلاعات تماس | ایمیل واقعی، شماره تماس نمایشی و لینک `tel:`، نشانی، ساعات پاسخ‌گویی |
| شبکه‌های اجتماعی | لینک اینستاگرام، لینکدین، تلگرام، واتس‌اپ (خالی بگذارید تا نمایش داده نشود) |
| دکمه اقدام | متن و لینک دکمه سراسری، متن پایین فوتر، کپی‌رایت |
| هیرو | متن بالای عنوان و در صورت داشتن ویدیو، آدرس MP4 و پوستر |
| سئو | توضیح متای پیش‌فرض، تصویر Open Graph، کد تأیید سرچ کنسول |

سپس:

1. **تنظیمات → خواندن** — صفحه اصلی باید روی «صفحه‌ای که انتخاب می‌کنم» و صفحه «خانه» باشد؛ صفحه نوشته‌ها روی «وبلاگ».
2. **تنظیمات → پیوندهای یکتا** — یک بار ذخیره کنید تا ساختار `/%postname%/` اعمال شود.
3. **نمایش → فهرست‌ها** — اگر می‌خواهید ساختار منو را تغییر دهید (منوها از قبل ساخته شده‌اند).

## ۵. فرم تماس و ارسال ایمیل

فرم تماس در صفحه «تماس» و هر جای دیگری که ویجت/شورت‌کد تماس باشد کار می‌کند:

- ارسال‌ها همیشه در **DaniSite → پیام‌های تماس** ذخیره می‌شوند؛ حتی اگر ارسال ایمیل هاست مشکل داشته باشد، پیام گم نمی‌شود.
- ایمیل اطلاع‌رسانی به آدرس واردشده در تب «اطلاعات تماس» می‌رود.
- برای تحویل مطمئن ایمیل، یک افزونه SMTP (مثل WP Mail SMTP) با سرویس میل واقعی تنظیم کنید؛ `mail()` خالص هاست‌های اشتراکی معمولاً اسپم می‌شود.
- فرم دارای nonce، هانی‌پات ضد اسپم، محدودیت طول فیلدها و throttle یک‌دقیقه‌ای بر پایه IP است.

## ۶. مجوز پوشه‌ها

- `wp-content/uploads` باید قابل نوشتن برای کاربر وب‌سرور باشد (`755` برای پوشه‌ها، `644` برای فایل‌ها، مالک کاربر وب‌سرور).
- اگر تصاویر آپلود نمی‌شوند، ابتدا همین مورد را بررسی کنید.

## ۷. ویرایش بصری با Elementor

- تمام صفحات ساخته‌شده با Elementor قابل ویرایش‌اند (صفحه → ویرایش با Elementor).
- ویجت‌های اختصاصی در دسته **DaniSite** پنل المنتور قرار دارند: هیرو، هیرو ویدیویی، خدمات، نمونه‌کارها، نمونه‌کار کاروسل، وبلاگ، گالری، مقایسه قبل/بعد، تیم، نظرات، آمار، پرسش‌ها، دکمه اقدام، فرم تماس، شبکه‌های اجتماعی، لوگو، دکمه، تصویر، ویدیو، عنوان، هدر/ناوبری/فوتر و انیمیشن اسکرول.
- برای ساخت صفحه جدید با همین زبان طراحی، یک صفحه خالی بسازید، قالب «تمام عرض» را انتخاب کنید و از ویجت‌های دسته DaniSite استفاده کنید.

## ۸. چک‌لیست امنیت و سرعت برای سایت واقعی

- SSL فعال و `https` اجباری باشد.
- `WP_DEBUG` روی سایت واقعی خاموش باشد؛ `DISALLOW_FILE_EDIT` را در `wp-config.php` فعال کنید.
- افزونه پشتیبان‌گیری روزانه + به‌روزرسانی منظم وردپرس/المنتور.
- حذف قالب‌ها و افزونه‌های استفاده‌نشده.
- کش صفحات (افزونه کش یا کش سرور) به‌جز روی صفحات فرم و پیشخوان.
- تصاویر آپلودی با فرمت WebP/JPEG فشرده؛ اندازه‌های قالب (`dani-card`, `dani-wide`, `dani-portrait`, `dani-square`) خودکار ساخته می‌شوند.
- بعد از نصب، نقشه سایت (`/wp-sitemap.xml`) را در سرچ کنسول ثبت کنید.

## ۹. عیب‌یابی

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| صفحه اصلی سایت‌های دیگر یا بلاگ پیش‌فرض دیده می‌شود | صفحه اصلی تنظیم نشده | تنظیمات → خواندن → صفحه‌ای که انتخاب می‌کنم → «خانه» |
| استایل‌ها بارگذاری نمی‌شوند | کش یا تنظیمات کش سرور | کش را پاک کنید؛ دوباره پیوندهای یکتا را ذخیره کنید |
| تصاویر نمونه‌کارها نمایش داده نمی‌شوند | مجوز uploads یا درون‌ریزی ناقص | مجوز پوشه را درست و درون‌ریزی را دوباره اجرا کنید |
| فرم پیام می‌دهد «ارسال با خطا مواجه شد» | ایمیل هاست | افزونه SMTP را تنظیم کنید؛ پیام‌ها در پیشخوان ذخیره شده‌اند |
| صفحات با المنتور ویرایش نمی‌شوند | Elementor فعال نیست | Elementor را فعال کنید |
| ۴۰۴ روی صفحات | ساختار پیوند یکتا | تنظیمات → پیوندهای یکتا → ذخیره |

## ۱۰. نقشه انتقال از محیط تست به سایت واقعی

1. بکاپ از دیتابیس و فایل‌های سایت مقصد.
2. نصب سه بسته طبق بخش ۲.
3. اجرای درون‌ریزی طبق بخش ۳.
4. پر کردن تنظیمات واقعی (بخش ۴) و SMTP (بخش ۵).
5. تست مسیرها: `/`، `/about/`، `/services/`، `/portfolio/`، `/blog/`، `/contact/`، `/faq/`، `/terms/`، `/cookie-policy/` و یک نشانی ناموجود (باید ۴۰۴ بدهد).
6. ارسال یک پیام آزمایشی از فرم و بررسی رسیدن آن در «پیام‌های تماس» و ایمیل.
