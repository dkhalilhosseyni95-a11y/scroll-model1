# راهنمای تنظیمات و ویرایش MOON

## ۱. پنل تنظیمات MOON

مسیر: پیشخوان ← **MOON**. تنظیمات در یک آپشن ذخیره می‌شوند و بلافاصله به‌صورت CSS Variables روی سایت اعمال می‌شوند (بدون نیاز به بازسازی CSS).

| تب | چه چیزی را کنترل می‌کند |
| --- | --- |
| برند | نام برند، شعار، لوگوی حالت روز و لوگوی حالت شب (برای هدر و فوتر) |
| رنگ‌ها | شش رنگ اصلی برند: مشکی عمیق، زغالی، کرم، سفید گرم، طلایی مات، خاکستری |
| حالت شب | رنگ پس‌زمینه/سطح/متن/متن کم‌رنگ/طلایی و تم پیش‌فرض بازدیدکننده (روشن/تاریک/هماهنگ با سیستم) + متن دکمه تغییر تم |
| تایپوگرافی | فونت فارسی، فونت نمایشی و متنی انگلیسی، اندازه پایه |
| هدر | منبع هدر، چسبیدن، جمع‌شدن هنگام اسکرول، منوی وردپرس، نمایش/عدم نمایش جست‌وجو، حساب، علاقه‌مندی‌ها، سبد، دکمه تم، دکمه CTA |
| انیمیشن | فعال/غیرفعال کردن همه انیمیشن‌های ورود و مدت آن |
| هیرو | ویدئو MP4 پیش‌فرض، Poster، غیرفعال‌سازی ویدئو در موبایل |
| قابلیت‌ها | فیلترها، علاقه‌مندی‌های داخلی، Load More، تب راهنمای سایز، نشان تخفیف، بازگشت به بالا، متن فوتر |

## ۲. ویرایش صفحه اصلی با المنتور

صفحه اصلی یک سند المنتور واقعی است (Container + ویجت). مسیر: پیشخوان ← برگه‌ها ← «صفحه اصلی» ← **ویرایش با المنتور**.

ترتیب بخش‌های ساخته‌شده:

1. هیرو سینمایی (`moon-cinematic-hero`)
2. کارت‌های دسته‌بندی زنانه/مردانه (`moon-category-cards`)
3. جدیدترین محصولات (`moon-product-grid` — منبع: جدیدترین)
4. بنر کمپین با شمارش معکوس (`moon-campaign-banner`)
5. کالکشن منتخب فصل (`moon-product-grid` — منبع: منتخب)
6. پرفروش‌ترین‌ها (`moon-product-grid` — منبع: پرفروش‌ترین)
7. داستان برند (`moon-brand-story`)
8. مزایای خرید (`moon-benefits`)
9. خبرنامه (`[moon_newsletter]` در ویجت Shortcode)

هر ویجت در دسته **MOON** در پنل المنتور قرار دارد و کنترل‌های محتوا و استایل دارد: متن، تصویر، لینک، رنگ، تایپوگرافی، فاصله‌ها (Padding/Margin واکنش‌گرا)، حاشیه، گردی گوشه، سایه، نسبت تصویر، تعداد ستون و انیمیشن ورود.

## ۳. ویجت‌ها

| ویجت | مهم‌ترین کنترل‌ها |
| --- | --- |
| هدر شیشه‌ای MOON | لوگو روز/شب، منو، نمایش آیکون‌ها، CTA، Blur، رنگ شیشه (روز/شب)، حاشیه، گردی، سایه، تایپوگرافی |
| هیرو سینمایی MOON | ویدئو MP4، Poster، شفافیت Overlay، ارتفاع (دسکتاپ/تبلت/موبایل)، متن‌ها، دو CTA، موقعیت افقی/عمودی محتوا، انیمیشن |
| کارت‌های دسته‌بندی | Repeater کارت‌ها (تصویر، برچسب، عنوان، توضیح، لینک، متن دکمه)، تعداد ستون، نسبت تصویر، شدت Overlay |
| گرید محصولات | منبع (جدیدترین/منتخب/تخفیف‌دار/پرفروش/امتیاز)، دسته‌بندی، تعداد، ستون، لینک «مشاهده همه» |
| بنر کمپین | تصویر، برچسب، عنوان، متن، CTA، شمارش معکوس تا تاریخ مشخص، چیدمان Split/Overlay |
| داستان برند | تصویر، برچسب، عنوان، متن، امضا، CTA، سمت تصویر، ارتفاع تصویر |
| مزایای خرید | Repeater (آیکون، عنوان، توضیح)، تعداد ستون، رنگ آیکون |

گرید محصولات از شورت‌کد رسمی `[products]` ووکامرس استفاده می‌کند؛ بنابراین قیمت، تخفیف، موجودی و لینک محصول همیشه از داده واقعی ووکامرس می‌آید.

## ۴. هدر و فوتر

- هدر: هنگام بوت روی `wp_body_open` رندر می‌شود و هدر قالب را با CSS کنار می‌گذارد (`body.moon-core-header-active`). هیچ فایلی از Hello Elementor تغییر نمی‌کند.
- فوتر: روی `wp_footer` رندر می‌شود و شامل ستون برند، خبرنامه، منوهای فروشگاه/خدمات مشتریان و نوار پایانی است.
- اگر از قالب Header/Footer المنتور پرو استفاده می‌کنید، در تنظیمات MOON ← هدر ← «منبع هدر» را روی «هدر قالب / المنتور پرو» بگذارید.

دکمه تغییر تم، تعداد سبد خرید و تعداد علاقه‌مندی‌ها در هدر با AJAX/Fragments ووکامرس به‌روز می‌شوند.

## ۵. حالت روشن/تاریک

- کلید تغییر تم در هدر؛ انتخاب کاربر در `localStorage` (و کوکی برای بار اول) ذخیره می‌شود.
- اسکریپت کوچک و inline در `<head>` قبل از رندر اجرا می‌شود تا پرش رنگ (Flash) رخ ندهد.
- برای کاربران وارد‌شده، انتخاب در `user meta` ذخیره می‌شود.
- رنگ‌های هر دو حالت از پنل تنظیمات خوانده می‌شوند؛ هیچ رنگ هارد‌کد شده‌ای در هدر، کارت محصول یا صفحات فروشگاه استفاده نشده است.

## ۶. فروشگاه و فیلترها

فیلترها روی صفحات فروشگاه و دسته‌بندی نمایش داده می‌شوند و به داده واقعی متصل‌اند:

- **قیمت:** روی `_price` محصول با `BETWEEN`
- **سایز / رنگ / جنس پارچه:** روی Attribute های ووکامرس (`pa_size`, `pa_color`, `pa_fabric`)
- **موجودی:** نمایش محصولات موجود
- **مرتب‌سازی:** همان لیست‌باکس رسمی ووکامرس
- **Load More:** با AJAX و همان کوئری فیلترها

فرم بدون جاوااسکریپت هم کار می‌کند: با ارسال معمولی GET، پارامترها روی کوئری آرشیو اعمال می‌شوند (`woocommerce_product_query`).

صفحه محصول شامل گالری ووکامرس، Variations واقعی، موجودی، افزودن به علاقه‌مندی‌ها، تب راهنمای سایز (قابل ویرایش در پنل) و محصولات مشابه است.

## ۷. علاقه‌مندی‌ها

- اگر **YITH WooCommerce Wishlist** فعال باشد، همه چیز به YITH واگذار می‌شود و Moon Core دکمه تکراری نمی‌سازد (لینک هدر به صفحه لیست YITH می‌رود).
- در غیر این صورت، سیستم سبک داخلی فعال است: ذخیره در `user meta` برای کاربران و کوکی برای مهمان‌ها، صفحه «علاقه‌مندی‌ها» با شورت‌کد `[moon_wishlist]`.

## ۸. دو زبانه بودن

- تمام رشته‌ها با text domain `moon-core` و توابع ترجمه نوشته شده‌اند؛ فایل `languages/moon-core.pot` برای ترجمه آماده است.
- استایل‌ها با CSS Logical Properties نوشته شده‌اند و فایل‌های RTL جداگانه (`moon-core-rtl.css`, `moon-commerce-rtl.css`) فقط اصلاحات جهتی دارند.
- برای محتوای دو زبانه، Polylang یا WPML را نصب کنید؛ محصولات، دسته‌ها و برگه‌ها با همان افزونه ترجمه می‌شوند (روش جایگزینی متن استفاده نشده است).
- کلاس‌های `moon-rtl` / `moon-ltr` روی `body` اضافه می‌شوند تا استایل‌های خاص هر جهت قابل هدف‌گیری باشد.

## ۹. سئو و دسترس‌پذیری

- تگ‌های معنایی (`header`, `nav`, `main`, `section`, `footer`)، یک `h1` در هر صفحه، عنوان‌های بخش‌ها `h2`.
- `alt` تصاویر محصول از نام محصول، `aria-label` روی دکمه‌های آیکونی، `aria-expanded` روی منوی موبایل و جست‌وجو، `aria-pressed` روی دکمه تم و علاقه‌مندی.
- Focus state مشخص (`:focus-visible` با رنگ طلایی)، پشتیبانی از `prefers-reduced-motion`، Skip-link خود قالب.
- Schema محصول و Breadcrumb از خود ووکامرس می‌آید.

## ۱۰. سرعت

- CSS اصلی همیشه، CSS فروشگاه فقط در صفحات ووکامرس بارگذاری می‌شود؛ JS با `defer` و تنها یک فایل.
- فونت‌ها self-host و `preload` شده‌اند؛ هیچ درخواست خارجی (Google Fonts/CDN) وجود ندارد.
- تصاویر با `loading="lazy"` (به‌جز هیرو) و `aspect-ratio` برای جلوگیری از Layout Shift.
- ویدئوی هیرو با `preload="metadata"`، `loop`، `muted` و امکان غیرفعال‌سازی در موبایل.
