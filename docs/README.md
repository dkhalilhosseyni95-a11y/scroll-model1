# MOON — قالب فروشگاهی لوکس (نسخه ۲.۱.۰)

مستندات رسمی قالب **MOON** و افزونه **MOON Demo Importer**.
مخزن شامل هر دو بسته است؛ قالب یک بستهٔ یک‌پارچه است و به افزونهٔ جانبی نیاز ندارد.

- قالب: `wp-content/themes/moon-theme` → بستهٔ `dist/moon-theme-final.zip`
- درون‌ریز دمو: `wp-content/plugins/moon-demo-importer` → بستهٔ `dist/moon-demo-importer-final.zip`

---

## ۱. پیش‌نیازها

| مورد | حداقل |
| --- | --- |
| WordPress | ۶.۴ (تست‌شده تا ۶.۹) |
| PHP | ۷.۴ |
| WooCommerce | ۸.۰ به بالا (در محیط توسعه ۱۱.۳ نصب می‌شود) |
| حافظهٔ PHP | ۲۵۶ مگابایت |

نصب:

1. `moon-theme-final.zip` را از **نمایش → پوسته‌ها → افزودن → بارگذاری** نصب و فعال کنید.
2. ووکامرس را نصب و فعال کنید.
3. از **نمایش → MOON** یا منوی **MOON** در پیشخوان، پنل را باز کنید.
4. برای محتوای نمونه: `moon-demo-importer-final.zip` را نصب، فعال و از صفحهٔ **MOON → دمو** مراحل مورد نظر را اجرا کنید.

> فعال‌سازی قالب به‌صورت خودکار صفحه‌ها، منوها و تنظیمات پایهٔ فروشگاه را می‌سازد (`inc/auto-setup.php`). اگر ووکامرس بعد از قالب فعال شود، اجرای دوبارهٔ همین روتین نواقص را کامل می‌کند.

## ۲. پنل MOON

تنظیمات در یک گزینهٔ واحد ذخیره می‌شوند (جدا از محتوای قالب)، بنابراین به‌روزرسانی قالب تنظیمات را از بین نمی‌برد. تعریف هر فیلد در `inc/core/settings/schema.php` است و هر فیلد مستقیماً به یک قابلیت واقعی متصل است (بدون فیلد تشریفاتی).

| بخش پنل | چه چیزی را کنترل می‌کند |
| --- | --- |
| **صفحه اصلی** | هیرو، دسته‌بندی‌ها، رگال، استودیو، محصولات، کمپین، داستان برند، داستان اسکرولی، نظرات، خبرنامه |
| **ظاهر و طراحی** | رنگ‌ها، فونت و تایپوگرافی، چیدمان و استایل، انیمیشن |
| **هدر** | چیدمان، عناصر و ترتیب آن‌ها، نوار اطلاع‌رسانی |
| **فوتر** | ستون‌ها، محتوا و تماس، شبکه‌های اجتماعی |
| **فروشگاه** | صفحهٔ فروشگاه، کارت محصول، صفحهٔ محصول، سبد خرید و تسویه |
| **حساب کاربری** | ورود و ثبت‌نام با شمارهٔ موبایل |
| **موبایل** | چیدمان موبایل، نوار پایین، منوی کشویی |
| **عملکرد و سرعت** | سوئیچ‌های بهینه‌سازی (CSS بلوکه، ایموجی، embed، lazy-load، حذف zoom) |
| **سئو و کد سفارشی** | متا، Open Graph، کد سفارشی هدر/فوتر |

داشبورد پنل آمار واقعی فروشگاه (محصولات، سفارش‌ها، فروش، مشتریان، پرفروش‌ها، نمودار و هشدارهای پیکربندی) را از خود ووکامرس می‌خواند؛ کوئری‌ها سقف دارند و نتیجه ۵ دقیقه کش می‌شود (`inc/core/admin/class-moon-stats.php`).

## ۳. سازندهٔ صفحه اصلی، هدر و فوتر

سه ماژول مستقل، بدون نیاز به المنتور:

- `inc/core/modules/class-moon-sections.php` — بخش‌های صفحه اصلی، ترتیب و فعال/غیرفعال بودن.
- `inc/core/modules/class-moon-header.php` — چیدمان هدر و ترتیب عناصر.
- `inc/core/modules/class-moon-footer.php` — ستون‌ها و محتوای فوتر.

هر بخش قالب خود را در `template-parts/homepage/` دارد؛ افزودن بخش تازه یعنی یک فایل قالب + یک ردیف در آرگومان‌های سازنده.

## ۴. توکن‌های طراحی

همهٔ رنگ‌ها، فونت‌ها و فاصله‌ها متغیر CSS هستند (`inc/core/design/class-moon-tokens.php` + `assets/css/base.css`). خروجی پنل، متغیرها را در `:root` بازنویسی می‌کند؛ هیچ رنگ یا فونتی در فایل‌های CSS به‌صورت hard-code باقی نمانده است.

فونت‌ها به‌صورت self-hosted (Vazirmatn برای فارسی، Cormorant Garamond برای لاتین) با `font-display: swap` بارگذاری می‌شوند.

فایل‌های CSS:

```
assets/css/base.css          توکن‌ها و پایه
assets/css/header-footer.css هدر و فوتر
assets/css/homepage.css      بخش‌های صفحه اصلی
assets/css/shop.css          آرشیو فروشگاه و فیلترها
assets/css/cards.css         کارت محصول
assets/css/pages.css         صفحه‌های داخلی، وبلاگ، تماس
assets/css/woocommerce.css   بازنویسی قالب‌های ووکامرس
assets/css/woo-extras.css    مقایسه، کوئیک‌ویو، سبد کشویی
assets/css/extensions.css    افزونه‌های ظاهری
assets/css/mobile.css        چیدمان موبایل و نوار پایین
```

## ۵. ورود و ثبت‌نام با تأیید موبایل (OTP)

ماژول `inc/core/modules/class-moon-otp.php` با جریان دو مرحله‌ای:

1. دریافت شمارهٔ موبایل و ارسال کد یک‌بارمصرف.
2. تأیید کد و ساخت/ورود کاربر.

نکات امنیتی پیاده‌شده: نرخ‌محدودی درخواست، انقضای کد، هش کد در پایگاه‌داده، غیرفعال‌سازی کد پس از استفاده، nonce روی همهٔ درخواست‌های AJAX و پاک‌سازی ورودی‌ها. برای ارسال پیامک، درگاه پیامک از طریق فیلتر `moon_otp_send_sms` وصل می‌شود؛ در محیط توسعه کد در لاگ ثبت می‌شود.

نکته: صفحات حساب کاربری، تسویه و ورود، وابسته به نشست هستند؛ بازدیدکنندهٔ ناشناس فقط فرم ورود را می‌بیند.

## ۶. ابزارهای فروشگاهی

| قابلیت | محل |
| --- | --- |
| افزودن به سبد با AJAX و سبد کشویی | `inc/cart-ajax.php` |
| مقایسهٔ محصولات | `inc/core/modules/class-moon-compare.php` + `page-compare.php` |
| کوئیک‌ویو | `inc/core/templates/moon-quick-view.php` |
| جستجوی زنده | `inc/live-search.php` |
| علاقه‌مندی‌ها | `inc/integrations/woocommerce.php` |
| نظرات و امتیاز محصول | `inc/reviews.php` |
| تسویهٔ حساب و درگاه | `inc/checkout.php` + `inc/gateways/zibal.php` |
| خبرنامه | `inc/newsletter.php` |

تسویه در محیط توسعه با «پرداخت در محل» کار می‌کند؛ درگاه واقعی را فروشگاه‌دار در **ووکامرس → تنظیمات → پرداخت** تنظیم می‌کند.

## ۷. عملکرد و سئو

`inc/performance.php` سوئیچ‌های پنل را می‌خواند و اگر قابلیتی خاموش باشد، اسکریپت/استایل مربوطه هم بارگذاری نمی‌شود (بدون شرط‌های سراسری). `inc/seo.php` متا، Open Graph و داده‌های ساختاریافته را تولید می‌کند.

## ۸. درون‌ریز محتوای دمو

`inc/class-moon-demo-importer.php`:

- مراحل مستقل: محصولات، رگال، استودیو، ژورنال، صفحه‌ها، منو، تنظیمات فروشگاه — هر مرحله از طریق چک‌باکس قابل انتخاب است.
- پیش از نخستین مرحله از تنظیمات جاری نسخهٔ پشتیبان گرفته می‌شود.
- شناسهٔ همهٔ آیتم‌های ساخته‌شده ذخیره می‌شود؛ **Rollback** آخرین اجرا را برمی‌گرداند (موارد ساخته‌شده حذف و تنظیمات قبلی بازگردانده می‌شوند).
- همهٔ مراحل idempotent هستند: اجرای دوباره آیتم تکراری نمی‌سازد.
- همهٔ AJAXها با `check_ajax_referer` محافظت می‌شوند.

## ۹. محیط توسعه (Base44 sandbox)

```bash
docker compose -f docker-compose.base44.yml up -d --build
docker compose -f docker-compose.base44.yml ps          # db / wordpress / setup باید healthy باشند
```

| سرویس | نقش |
| --- | --- |
| `db` | MariaDB 11.4 با حجم ماندگار |
| `wordpress` | Apache + PHP 8.3، فروشگاه روی پورت ۳۰۰۰ |
| `setup` | نصب‌کنندهٔ یک‌باره: هستهٔ وردپرس، ووکامرس، فعال‌سازی قالب و افزونه، محتوای دمو و تنظیمات فروشگاه. پس از پایان فایل `.moon-setup-ok` را می‌نویسد و زنده می‌ماند تا healthcheck وضعیت نصب را تأیید کند |

- قالب و افزونه bind-mount هستند؛ ویرایش PHP/CSS/JS بدون build دیده می‌شود.
- ورود پیشخوان در سندباکس: `admin` / `moon-dev-admin`.
- نشانی سایت در پایگاه‌داده `http://localhost:3000` است؛ با `BASE44_PREVIEW_MODE=1` افزونهٔ mu در `docker/mu-plugins` میزبان را در هر درخواست بازنویسی می‌کند. مقدار میزبان سندباکس را هرگز دستی در فایل‌ها نگذارید.
- پیوندهای یکتا `/%postname%/` هستند: `/shop/`، `/product/<slug>/`، `/cart/`، `/checkout/`، `/my-account/`، `/compare/`، `/journal/`.

## ۱۰. ساخت بسته‌های نهایی

```bash
bash tools/build-packages.sh
# dist/moon-theme-final.zip
# dist/moon-demo-importer-final.zip
```

میزبان سندباکس `zip` ندارد، بنابراین بسته‌بندی با `tools/package.php` و کلاس `ZipArchive` داخل ایمیج `wordpress:cli-php8.3` انجام می‌شود. هر دو zip یک پوشهٔ ریشهٔ درست (`moon-theme/` و `moon-demo-importer/`) دارند و مستقیماً از پیشخوان وردپرس نصب می‌شوند.
