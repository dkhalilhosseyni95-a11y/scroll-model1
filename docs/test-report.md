## باگ‌هایی که در همین تست‌ها پیدا و رفع شد

1. **بارگذاری کلاس پایه ویجت** پیش از المنتور → خطای Fatal. اکنون داخل `elementor/widgets/register` بارگذاری می‌شود.
2. **ترتیب بارگذاری ووکامرس**: Moon Core پیش از ووکامرس بارگذاری می‌شد و هیچ هوک فروشگاهی ثبت نمی‌شد → اکنون روی `plugins_loaded` با اولویت ۲۰.
3. **فایل RTL** با `wp_style_add_data('rtl','replace')` جای کل استایل پایه را می‌گرفت و سایت بدون استایل می‌شد → اکنون فایل RTL به‌صورت افزودنی بارگذاری می‌شود.
4. **فیلترهای AJAX** فقط از `$_GET` می‌خواندند و فیلترها اعمال نمی‌شدند → خواندن از POST و GET با sanitize یکسان.
5. **خصیصه `hidden`** منوی موبایل با `display:flex` بی‌اثر شده بود → قاعده `[hidden]{display:none !important}`.
6. **WooCommerce "به‌زودی"** (`woocommerce_coming_soon`) صفحه فروشگاه را برای مهمان پنهان می‌کرد → در درون‌ریز و اسکریپت نصب غیرفعال می‌شود.
7. **کش المنتور** (`_elementor_element_cache`) مانع دیده‌شدن تغییرات درون‌ریزی می‌شد → هنگام به‌روزرسانی سند پاک می‌شود.

## مواردی که در این محیط تست **نشده‌اند** (صادقانه)

| مورد | دلیل | وضعیت |
| --- | --- | --- |
| کلیک واقعی «اعمال فیلتر» در مرورگر | صفحه آرشیو وردپرس ناوبری کامل دارد و ابزار تست مرورگر در این محیط فقط روی سند جاری اجرا می‌شود | مسیر سرور و همین هندلر با درخواست واقعی AJAX تأیید شد؛ خود کلیک باید دستی بررسی شود |
| افزودن به سبد و تسویه‌حساب | همان محدودیت ناوبری؛ منطق آن ۱۰۰٪ از ووکامرس است | صفحه سبد خرید ۲۰۰ برمی‌گرداند، فرم Variations رندر می‌شود؛ جریان خرید دستی تست شود |
| اجرای قالب‌های Header/Footer المنتور پرو | Elementor Pro افزونه پولی است و نصب نشده | فایل‌های JSON تولید و صحت ساختاری آن‌ها بررسی شده؛ درون‌ریزی دستی لازم است |
| YITH Wishlist / Gravity Forms / LiteSpeed Cache | نصب نشده‌اند | سازگاری از روی هوک‌ها و بررسی کد (بدون تغییر فایل دیگران)؛ تست میدانی انجام نشده |
| ویرایشگر المنتور (Drag & Drop) | فقط فرانت‌اند در مرورگر بررسی شد | ویجت‌ها با API رسمی ثبت شده‌اند و کشوی MOON در پنل نمایش داده می‌شود؛ تجربه ویرایش دستی توصیه می‌شود |
| رابط انگلیسی (LTR) | لوکال سایت فارسی است | ساختار ترجمه (POT، text domain، CSS منطقی و RTL جدا) آماده است؛ فایل ترجمه انگلیسی هنوز ساخته نشده |

## کارهای باقی‌مانده پیشنهادی (مرحله بعد)

- تولید فایل ترجمه انگلیسی (`moon-core-en_US.po/.mo`) و تست رابط LTR
- تست میدانی با YITH Wishlist، Gravity Forms و LiteSpeed Cache روی هاست واقعی
- افزودن تست خودکار PHPUnit برای sanitize تنظیمات و سازنده کوئری فیلترها
- درون‌ریزی قالب‌های Header/Footer در Elementor Pro و تنظیم شرط نمایش Entire Site
