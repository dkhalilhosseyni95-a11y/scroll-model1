قالب حرفه‌ای دنی سایت — استودیوی طراحی و توسعه وب. کامل RTL، سازگار با Elementor، بهینه برای سرعت و سئو.

== Description ==

قالب والد DaniSite شامل طراحی کامل صفحه اصلی، صفحات داخلی، آرشیوها، مطلب تک‌نویس، جست‌وجو و ۴۰۴ است.
پالت رنگ، تایپوگرافی (فونت Vazirmatn به‌صورت محلی) و فاصله‌گذاری‌ها بر پایه هویت بصری طراحی اصلی پروژه پیاده‌سازی شده‌اند.

بخش‌های اصلی سایت (خدمات، نمونه‌کارها، تیم، نظرات، پرسش‌ها، وبلاگ و فرم تماس) با افزونه همراه «DaniSite Core» مدیریت می‌شوند.
برای استفاده کامل، افزونه DaniSite Core نصب و فعال باشد؛ در غیر این صورت صفحات با استایل قالب ولی بدون بخش‌های پویا نمایش داده می‌شوند.

== Installation ==

1. قالب `danisite-parent.zip` را از نمایش → پوسته‌ها → افزودن پوسته نصب کنید (فعال نکنید).
2. قالب فرزند `danisite-child.zip` را نصب و فعال کنید.
3. افزونه `danisite-core.zip` را نصب و فعال کنید.
4. افزونه Elementor را نصب و فعال کنید.
5. از منوی DaniSite → راه‌اندازی و درون‌ریزی، محتوای نمونه را بسازید.
