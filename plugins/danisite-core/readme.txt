هسته دنی سایت: نوع‌های محتوا، ویجت‌های اختصاصی المنتور، تنظیمات سایت، سئو، فرم تماس و درون‌ریز کامل سایت.

== Description ==

این افزونه تمام قابلیت‌های محتوایی قالب DaniSite را فراهم می‌کند:

* نوع‌های محتوا: خدمات، نمونه‌کارها (با دسته‌بندی)، اعضای تیم، نظرات مشتری، پرسش‌های متداول و پیام‌های تماس.
* بیش از ۳۰ ویجت اختصاصی المنتور در دسته «DaniSite».
* شورت‌کد برای همه بخش‌ها (پشتیبان بدون المنتور).
* یک صفحه تنظیمات برای اطلاعات تماس، شبکه‌های اجتماعی، دکمه اقدام، هیرو و سئو.
* سئوی داخلی: متا، canonical، Open Graph، JSON-LD و robots (در صورت وجود افزونه سئو، خودکار غیرفعال می‌شود).
* فرم تماس امن با ذخیره پیام، هانی‌پات، nonce و throttle.
* درون‌ریز یک‌کلیکی و idempotent با پشتیبان‌گیری و بازگردانی.

== Installation ==

1. افزونه را از پیشخوان نصب و فعال کنید.
2. Elementor را نصب و فعال کنید.
3. منوی DaniSite → راه‌اندازی و درون‌ریزی → دکمه درون‌ریزی.
